# Writing, design and research

Every row also meets the craft bar in `../craft.md`: no slop, thought-through titles and navigation, and UI built from references.

| Kind | Bar | The critic inspects |
|---|---|---|
| Writing (docs, posts, copy) | A model text the person admires, plus the brief's must-haves | The finished text, in a blind comparison with the model: "which is better, and why?" |
| UI and visual design | Screenshots of a product people admire, plus the design system | The rendered screens at each size and in each text direction, side by side with the reference |
| Research | Every claim tied to a source that was opened and read | Each citation: the source exists and says what is claimed. Count the claims that have no source |
| Data and analysis | The figure recomputed independently, and stable when inputs change | It reruns the numbers from the raw data |
| Prompts, skills, agents | A fixed set of test cases with expected behaviour | It runs the cases and compares against the previous version |

## Notes

- Blind comparison: show the two items as A and B in random order, and ask which is better against the bar. Record which one was ours in the state, not in the critic's brief.
- Taste work never really "passes", so give it a fixed budget and stop when two rounds bring no gain.
- Research critics fail any claim whose source they could not open, however plausible it sounds.
